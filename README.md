# 311 Staten Island — анализ обращений жителей

Аналитика обращений в городскую службу 311 Нью-Йорка на открытых данных.
Весь расчёт — SQL, PostgreSQL 18. Визуализация — Yandex DataLens.

**[→ Интерактивный дашборд](https://datalens.yandex/bdjgdyt772bsu?_share_link=public)**

---

## Бизнес-вопрос

Как городские службы Статен-Айленда справляются с обращениями жителей:
сколько времени уходит на закрытие, где узкие места, что можно улучшить.

**Ограничение среза.** Фильтр при выгрузке стоял только на `created_date`.

## Архитектура

Два слоя.

**`requests_raw`** — сырой слой, 21 колонка, все `text`.
Объяви дату датой — одна кривая строка уронит весь импорт. Сырой слой
принимает что угодно, типы и мусор разбираются потом запросами.

**`requests`** — чистый слой, 24 колонки. Типы приведены, добавлены три флага качества:

| Флаг | Что означает | Записей |
|---|---|---|
| `is_closed` | статус = `Closed` | 131 819 |
| `has_closed_at` | дата закрытия заполнена | 131 951 |
| `is_duration_valid` | обе даты есть и закрытие не раньше создания | **131 927** |

**Строки не удаляются — помечаются флагами.** Одна таблица обслуживает
все вопросы, каждый расчёт сам решает, по какому флагу фильтровать.

**База выбирается под вопрос, а не одна на весь проект:**

| Вопрос | База | Число |
|---|---|---|
| Сколько обращений поступило | все строки | 134 301 |
| Какая доля закрыта | `is_closed` | 131 819 |
| Сколько времени занимает закрытие | `is_duration_valid` | 131 927 |

## Дашборд

**[311 Staten Island — обращения жителей, 2025](https://datalens.yandex/bdjgdyt772bsu?_share_link=public)** — Yandex DataLens, публичный доступ.

Источник дашборда — витрина `mart_requests` из `07_funnel_mart.sql`: зерно «одно обращение»,
134 301 строка, детальная, а не агрегированная. Агрегирует сама BI-система, поэтому новый
вопрос к данным не требует нового SQL.

| Что на дашборде | Форма |
|---|---|
| Всего обращений | индикатор |
| Поток по месяцам | линия |
| Топ-10 типов жалоб | горизонтальные столбцы |
| Объём по службам | горизонтальные столбцы |
| Медиана срока закрытия по службам | горизонтальные столбцы |
| Распределение по корзинам срока | горизонтальные столбцы |

Фильтры: служба, тип жалобы, период. Фильтр периода стоит на дате **поступления**
обращения (`created_at`), а не на дате закрытия — иначе 2 350 незакрытых обращений
выпали бы из выборки целиком.

**Ограничение разрезов по службам.** На графиках показаны девять служб с объёмом
1000+ обращений за год. Медиана по меньшим группам статистически ненадёжна: без
этого порога первые места занимали службы с единицами обращений и срок в сотни
дней, а реальная находка (DOB — 20.97 дня на 4 456 обращениях) была не видна.
